This is a "Mini Inventory System" program I created as my final project in my dual credit object-oriented programming class at SAIT, which I recieved full marks for. (hooray!)

The system uses two classes (Product and Inventory)
As well as other concepts such as variables, loops, conditionals, lists, functions, classes, and basic file I/O.

🌠 What the project does: Allows the user to load products from a file, allow the user to add, sell, and restock products, display all
products, and save the updated data back to the file when the program exits.

🌷 Why the project is useful: The given scenario for the project is that a small shop currently tracks its inventory by hand. They want a simple computer program that can make the process easier.

🐇 How users can get started with the project: Download the repository and run the main.py file. The program will prompt you what to input from there.
